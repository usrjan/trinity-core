# trinity-core

Минимальное ядро системы Trinity. Три таблицы. Одна любовь.

## Что это

Trinity — система, в которой всё является нейроном. Пользователи, страницы, меню, детали, проекты, настройки. Всё хранится в трёх таблицах:

| Таблица  | Назначение                                      |
|----------|--------------------------------------------------|
| neuron   | Сущности: от пользователя до страницы           |
| synapse  | Связи: роли, отношения, вхождения                |
| text     | Мультиязычные тексты: названия, описания         |

## Стек

- PHP 8.4+
- Symfony 8 (Routing, HttpFoundation, Dotenv, Validator)
- Twig 3
- Doctrine DBAL 4
- PHP-DI 7
- Bootstrap 5 + Bootstrap Icons
- Vanilla JS

## Установка

1. `composer install`
2. Скопировать `.env.example` в `.env`
3. Заполнить параметры базы
4. Импортировать `seed.sql`
5. Настроить веб-сервер на `public/`

## Плагины

| Плагин   | Что делает                       |
|----------|----------------------------------|
| spa      | Морда сайта, меню, страницы      |
| admin    | Админ-панель                     |
| users    | Вход, регистрация, профиль       |
| monitor  | Логи, страница ошибки            |
| guard    | Безопасность, CSRF, блокировки   |
| map      | Карта, GeoJSON                   |
| tools    | Инструменты, отчёты              |
| gallery  | Галерея изображений              |

## Роуты

1. **Файловые** — `config/routes.php` (минимальные)
2. **Плагины** — `plugins/*/plugin.php`
3. **База** — нейроны `type='route'`

## Конфигурация

- `.env` — переменные окружения
- Нейроны `type='config'` — настройки приложения

## Философия

Ядро не меняется. Плагины добавляют функциональность.
База — источник истины. Код — её отражение.
