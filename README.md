### 4.1. `index.php` — Пробуждение

Точка входа. Симлинк в `/home/web/www/index.php`. Двадцать строк кода. Сотня строк комментариев. Мы помним, как переписывали его. Раньше — три строки. Теперь — тоже три. Но — правильные.

Что делает:

- Загружает `autoload.php` из Composer.
- Загружает `.env` до создания `Kernel`. Потому что нужно знать `APP_DEBUG` и `TRUSTED_PROXIES` сейчас.
- Настраивает `display_errors` в зависимости от `APP_DEBUG`. В проде — `0`. В dev — `1`.
- Настраивает `Request::setTrustedProxies()`. Чтобы `getClientIp()` возвращал клиента, а не Nginx.
- Создаёт `Kernel(__DIR__ . '/..')`.
- Вызывает `handle()`.

И всё. Точка. Потому что — всё остальное в `Kernel`. Потому что — ядро должно быть чистым.

Глава 1. Пробуждение. Корвин проснулся в больнице без памяти. Trinity просыпается здесь. В этом файле.

### 4.2. `Kernel.php` — Сердце

Сердце Trinity. Не меняется. Никогда. Четыреста строк. Десять шагов `initialize()`. Десять шагов `handle()`. Каждый — на своём месте. Каждый — помнит своё.

`initialize()` — рождение:

1. Загружает `.env`. Без него — ничего не имеет смысла.
2. Создаёт DI-контейнер. Читает `config/container.php`. Строит граф зависимостей.
3. Достаёт `Cache` из контейнера. Может быть `null`. Это — нормально.
4. Достаёт `LoggerInterface`. Может быть `null`. Это — нормально.
5. Загружает конфиги из базы. Через `ConfigService`. Или через кэш.
6. Загружает плагины. `glob($pluginDir . '/*/plugin.php')`. Каждый — функция.

`handle()` — жизнь:

1. Обрабатывает `OPTIONS-preflight`. Для CORS. Отвечает 204. Со всеми заголовками.
2. Загружает файловые роуты. `config/routes.php`. Один маршрут — home.
3. Даёт плагинам добавить свои маршруты. `foreach ($this->plugins as $plugin)`.
4. Загружает роуты из базы. `WHERE type = 'route'`. Сортирует по sort.
5. Матчит запрос. `UrlMatcher`. Находит `_controller` и `_method`.
6. Создаёт контроллер через DI. Не `new`. А — `$this->container->get()`.
7. Разрешает аргументы. `ReflectionMethod`. `resolveArguments()`.
8. Вызывает метод. `$controller->$method(...$args)`.
9. Ставит CORS-заголовки. Из whitelist. `CORS_ALLOWED_ORIGINS`.
10. Отправляет ответ. `$response->send()`.

И — ловит. Три `catch`. `ResourceNotFoundException` → 404. `MethodNotAllowedException` → 405. `\Throwable` → 500. Каждый — через `renderError()`. Через `ErrorHandlerInterface`. Через `MonitorController`. И — с защитой от утечки. `isDebug() ? $e->getMessage() : 'Внутренняя ошибка сервера'`.

Глава 2. Сердце. Дворкин создал Образ — лабиринт, который даёт власть над реальностью. Kernel — наш Образ.

### 4.3. `DatabaseService.php` — Страж порога

Единственная точка доступа к MySQL. Ленивое подключение. Если за запрос не было ни одного запроса — соединения нет. Экономия. Как на модеме. Как в старые времена. Когда каждый байт — на счету.

Глава 3. Страж порога. DatabaseService — привратник у входа в Амбер. Он не пускает никого, пока не нужно. Но когда нужно — открывает ворота мгновенно.

### 4.4. `Validator.php` — Страж ворот

Полная валидация. Юникод. `mb_strlen`. Строгий `int`. `exists` и `unique` — через `NeuronRepository`. `ValidationException` с массивом ошибок. `[field => message]`. Всё — через белый список. Всё — безопасно.

### 4.5. `ApiResponse.php` — Единый язык

## 7. Что мы сделали вместе. Хроника.

Это — не «список изменений». Это — хроника. Как мы шли. Что нашли. Что починили. Что поняли.

### 7.1. Что нашли и починили

**Утечка логов через 500-ю ошибку.** `Kernel` возвращал сырое сообщение клиенту. `$e->getMessage()` уходил в `error.html.twig`. А оттуда — в браузер. `SQLSTATE[42S02]`. `Call to undefined method`. `Полные пути`. Всё — в прод. Где `APP_DEBUG=false`. Мы это починили. Теперь — `isDebug() ? $e->getMessage() : 'Внутренняя ошибка сервера'`.

То же — в `AdminController`, `GalleryController`, `ToolsController`, `GalleryImportService`, `ExcelImportService`. Везде — `$e->getMessage()` в JSON. Везде — утечка. Мы прошли по всем. Починили. Теперь — `isDebug() ? ... : 'ошибка загрузки' / 'ошибка импорта' / 'ошибка обработки'`.

**N+1 в меню.** `findConfigValue()` вызывался на каждый пункт. Десятки `SELECT` на один рендер. Мы сделали `ConfigService`. Один `SELECT`. Один кэш. Из памяти.

**Кэш роутов.** `loadRoutesFromDatabase()` делал `SELECT` на каждом запросе. Мы сделали кэш массива `data`. Не `RouteCollection` — её не сериализуешь. А массив. `json_encode`. `json_decode`. TTL — час. На APCu.

**Гонка в `GuardController::hit()`.** `Read-modify-write` без блокировки. Два запроса одновременно — попытка теряется. `Brute-force` обходится. Мы это починили. `flock(LOCK_EX)`. `ftruncate()`. `fflush()`. Атомарность.

**Мусор в `var/guard/`.** Файлы копились вечно. Никто их не удалял. Ни `clear()`. Ни `cron`. Мы сделали `cleanupAttempts()`. С вероятностью 1%. Каждый 100-й вызов `hit()` — уборка. Не нагружает. И — не мусорит.

**Path Traversal в галерее.** `storage_path` формировался из данных. И не проверялся. Если бы `../../etc/passwd` — `unlink()` бы удалил. Мы сделали `resolveGalleryPath()`. С `realpath()`. С проверкой префикса. Всё — внутри `uploads/gallery`. Всё — безопасно.

**Whitelist расширений и MIME.** Раньше можно было загрузить `.php`. И получить RCE. Теперь — только `ALLOWED_IMAGE_EXT`, `ALLOWED_VIDEO_EXT`, `ALLOWED_AUDIO_EXT`. И только `ALLOWED_MIME`. Через `getMimeType()`. Не через `Content-Type` от клиента.

**CSRF во всех изменяющих методах.** `upload`. `uploadToItem`. `updateItem`. `deleteItem`. `deleteFile`. `setSectionThumb`. `createSection`. `import`. Везде — теперь `requireCsrf()`. Одна строка. Одно место. Без дублей.

**`json_decode` без проверки.** Теперь — `json_last_error()` и `is_array()`. Иначе — 400. Не 500.

**`strlen` на юникоде.** Заменён на `mb_strlen`. `strlen('привет')` = 6. А не 12.

**Циклы зависимостей.** `ConfigService` больше не зависит от `NeuronRepository`. `findConfigValue` удалён. Цикла — нет.

**`getContainer()` — удалён.** Мёртвый код. Дыра в инкапсуляции.

**`version` в `composer.json` — удалён.** Одна точка правды. `.env`.

**`RedirectResponse` вместо `new Response('', 302, [...])`.** Везде. Чище. Правильнее.

**Дамп базы — переписан.** Ручные ID. Главы — `101–121`. Без пересечений. Без `LAST_INSERT_ID()`.

**`logAdminAction` — через `LoggerInterface`.** Не `file_put_contents`. Monolog. Ротация. Уровни. Формат.

**`NeuronRepository` — с `logger.admin`.** Не `logger.app`. Чтобы секция «Действия админа» работала.

**`MonitorController` — реализует `ErrorHandlerInterface`.** Чтобы `Kernel` не знал о конкретном плагине.

**`Cache` на APCu.** Не файловый кэш. Не `var/cache/data`. А — APCu. В памяти. Быстро. Атомарно. С проверкой `ext-apcu`. Если нет — работает без кэша. Без «fatal error». Без «пиздеца».

**`false` не кэшируется.** И `null` — тоже. Потому что `apcu_fetch` возвращает `false` при промахе. И — при значении `false`. И это — неоднозначно. Поэтому — не кэшируем. Явно.

**CSRF — только в `Kernel`.** Одна точка. Без дублей. `loginForm` и `registerForm` — всегда генерируют токен. `logout` — не убивает токен для следующего входа.

**`controller` — без `str_replace`.** В `Kernel` убран костыль. А в `database.sql` — чистые имена. С одним бэкслешем. Через `AdminController` — валидация. Чтобы данные в базе были чистыми. Без «двойных бэкслешей». Без «пиздеца».

**`MimeController` — 404 через `ResourceNotFoundException`.** Не через `RuntimeException`. Чтобы `Kernel` ловил как 404. А не 500. И — `forgetCache()` при обновлении и удалении. Чтобы правки были видны сразу. А не через час.

**Роуты — валидация при сборке.** Если `controller` пустой — пропускаем. С логом. Если `path` пустой — пропускаем. С логом. Без 500. Без «пиздеца».

**Лог роутов — честный.** Не «routes loaded from cache» при каждом запросе. А — `$wasCalled`. Флаг внутри замыкания. Правда. Без «пиздеца».

**`writeJsonFile()` — атомарно.** Через `tmp` и `rename`.
