# Архитектура Trinity

## Слои

1. **Ядро (`src/`)** — базовые классы: Kernel, ApiResponse, Cache, Validator, DatabaseService, репозитории.
2. **Плагины (`plugins/`)** — функциональные модули: spa, admin, users, monitor, guard, map, tools, gallery.
3. **Публичная часть (`public/`)** — стили, скрипты, загружаемые файлы.

## Поток запроса

HTTP-запрос
→ index.php
→ Kernel::handle()
→ .env
→ DI-контейнер
→ конфиг из базы
→ плагины
→ роуты (файл → плагины → база)
→ матчинг маршрута
→ контроллер
→ ответ

## Связи

- Ядро не зависит от плагинов.
- Плагины зависят от ядра и друг от друга через DI.
- База данных — единственный источник данных.
- DWG/Excel/Word — производные артефакты.

## Принципы

- **Нейрон — всё.** Даже роут и настройка — нейроны.
- **Синапс — связь.** Роль, вхождение, отношение.
- **Текст — значение.** Название и описание на любом языке.
- **Модульность.** Плагин не трогает чужой код.
- **Кэш.** Всё, что можно закэшировать, должно кэшироваться.
